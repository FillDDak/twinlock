# See drift the moment it happens

Change the code inside a linked block, without saving:

- The block is **tinted**, and its CodeLens says which linked code still needs updating.
- The **other file** shows *Needs update* on its block, and both appear in the **Problems** panel.
- Hover a target to **preview** the linked code. Press **F12** to jump to it.

Update the other side too, and the warnings disappear on their own.
If no change is needed there, choose **Acknowledge**.
